THALORNE is a pure-Python, stdlib-only program that draws a vintage travel poster of a floating island — its waterfall pouring into a sunset sea, a lighthouse on its green plateau — and sets the invented place's name in large hand-drawn capitals.

## Run it

```sh
python3 main.py
```
